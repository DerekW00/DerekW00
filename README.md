## Start here: LLM Reliability Lab

[**llm-reliability-lab**](https://github.com/DerekW00/llm-reliability-lab) is an offline Python evaluation harness for structured invoice extraction. It demonstrates how a schema-valid change can corrupt an invoice identifier, how field-level metrics and critical-error gates catch it, and how a baseline comparison verifies the repair.

It uses **synthetic documents and authored predictions**. It demonstrates evaluation mechanics; it does not report live-model accuracy or production results.
